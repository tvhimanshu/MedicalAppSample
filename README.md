# MedicalRAG — Patient Record Retrieval with GPT-4

RAG system that lets physicians query patient records in natural language.
Semantic search finds relevant records; GPT-4 generates citation-backed answers.

> All patient data is synthetic and for demonstration only.

## How it works

```
Doctor question
      │
      ▼
  embed(question)          ← OpenAI text-embedding-3-small
      │
      ▼
  VectorStore.search()     ← cosine similarity over patient documents
      │  top-5 chunks
      ▼
  generator.generate()     ← GPT-4o-mini with clinical system prompt
      │
      ▼
  **Summary** + Evidence [citations] + ⚠️ Alerts
```

## Setup

```bash
pip install -r requirements.txt
cp .env.example .env        # add your OPENAI_API_KEY
```

## Run

```bash
python ingest.py            # embed patient records → data/vector_store.pkl
python demo.py              # run preset doctor queries
python demo.py --interactive        # free-text query
python demo.py --patient pat-005    # scope to one patient
```

## Project structure

```
medrag/
  config.py          env-driven settings
  embedder.py        OpenAI embedding wrapper (single + batch)
  vector_store.py    in-memory numpy cosine similarity store
  generator.py       GPT-4 with clinical citation prompt
  pipeline.py        RAGPipeline.ask(question, patient_id)
data/
  patient_records.json    27 pre-chunked medical documents (6 patients)
  vector_store.pkl        generated by ingest.py
ingest.py           embed all documents → save store
demo.py             run doctor queries against the store
```
